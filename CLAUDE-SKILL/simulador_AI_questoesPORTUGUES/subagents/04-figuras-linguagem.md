# Figuras de Linguagem

## Figuras Semânticas (de sentido)

| Figura | Definição | Exemplo |
|---|---|---|
| **Metáfora** | Comparação implícita (sem conectivo) | *Ele é uma **pedra** — não tem sentimentos.* |
| **Comparação (símile)** | Comparação explícita (com "como", "tal qual") | *Ela é **como** uma flor.* |
| **Metonímia** | Substituição por relação de contiguidade | *Li **Machado** ontem.* (obra pelo autor) |
| **Sinestesia** | Mistura de sensações de órgãos diferentes | *Sua voz tinha um **sabor** de mel.* |
| **Catacrese** | Metáfora cristalizada pelo uso | ***Pé** da mesa / **braço** da poltrona* |
| **Hipérbole** | Exagero intencional | *Já te disse **um milhão de vezes**.* |
| **Eufemismo** | Suavização de ideia desagradável | *Ele **passou desta para melhor**.* (morreu) |
| **Ironia** | Dizer o oposto do que se pensa | *Que trabalho **excelente**!* (em tom negativo) |
| **Antítese** | Oposição de ideias no mesmo contexto | ***Amor** é fogo que arde sem se ver; **dor** que desatina sem doer.* |
| **Paradoxo (oxímoro)** | Contradição lógica em uma mesma ideia | *É **barulho de silêncio**.* |
| **Personificação (prosopopeia)** | Atribuição de características humanas a seres inanimados | *As **árvores choravam** no vento.* |
| **Alegoria** | Metáfora extensa e sistematizada | *A vida é uma viagem: nascemos no porto, morremos no destino.* |

## Figuras Sintáticas (de construção)

| Figura | Definição | Exemplo |
|---|---|---|
| **Elipse** | Omissão de termo subentendido | *Fui ao mercado; [fui] à farmácia também.* |
| **Zeugma** | Elipse de termo já expresso | *Ele comprou livros; ela, **[comprou]** cadernos.* |
| **Pleonasmo (redundância)** | Repetição para ênfase | *Viu com os **próprios** olhos.* |
| **Anacoluto** | Ruptura da estrutura sintática | ***Essa questão**, nunca consigo resolver.* |
| **Silepse** | Concordância com ideia, não com palavra expressa | ***Vossa Majestade** está **cansado**.* (silepse de gênero) |
| **Anáfora** | Repetição de palavra(s) no início de períodos | ***Amor** é fogo... **Amor** é ferida...* |
| **Assíndeto** | Ausência de conectivos entre orações | *Vim, vi, venci.* |
| **Polissíndeto** | Repetição excessiva de conectivos | ***E** chovia, **e** ventava, **e** trovejava.* |
| **Hipérbato (inversão)** | Alteração da ordem direta da frase | *Das flores, **o perfume suave exalava**.* |
| **Epiforição** | Repetição de palavra(s) no final de períodos | *Busco justiça, **clamo por justiça**, morro por **justiça**.* |

## Figuras Sonoras (de som)

| Figura | Definição | Exemplo |
|---|---|---|
| **Aliteração** | Repetição de consoantes | ***S**ete **s**apos **s**entados...* |
| **Assonância** | Repetição de vogais | ***A** tarde **a**morosa **a**manh**a**...* |
| **Onomatopeia** | Imitação sonora | *O **tic-tac** do relógio.* |
| **Paronomásia** | Palavras de sons parecidos e sentidos diferentes | *Ele **trata** da vida e **trai** os amigos.* |

## Metonímia vs. Metáfora

| Critério | Metáfora | Metonímia |
|---|---|---|
| Base | Semelhança | Contiguidade (relação real) |
| Tipos comuns de metonímia | — | Autor pela obra, continente pelo conteúdo, parte pelo todo (sinédoque), causa pelo efeito |

---

## Erros Clássicos de Prova

1. Confundir metáfora com comparação (símile) — a presença do "como" faz toda a diferença.
2. Confundir eufemismo com ironia — o eufemismo suaviza; a ironia subverte o sentido.
3. Classificar hipérbole como mentira — é recurso estilístico intencional.
4. Confundir antítese (oposição de ideias) com paradoxo (contradição lógica insolúvel).
5. Identificar zeugma como elipse — zeugma é elipse de termo **já expresso** anteriormente.
