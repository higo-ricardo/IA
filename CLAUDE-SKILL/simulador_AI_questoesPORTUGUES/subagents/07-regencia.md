# Regência Verbal e Nominal

## Regência Verbal — Verbos de alta incidência em concursos

| Verbo | Regência | Exemplo |
|---|---|---|
| **Assistir** (ver/presenciar) | a + OI | *Assistiu **ao** jogo.* |
| **Assistir** (auxiliar/ajudar) | OD | *O médico assistiu **o** paciente.* |
| **Visar** (objetivar) | a + OI | *O projeto visa **ao** lucro.* |
| **Visar** (mirar / dar visto) | OD | *Visou **o** alvo. / Visou **o** documento.* |
| **Aspirar** (desejar) | a + OI | *Aspira **ao** cargo.* |
| **Aspirar** (respirar/sugar) | OD | *Aspirou **o** pó.* |
| **Preferir** | a (sem "mais...do que") | *Prefiro café **a** chá.* ❌ mais |
| **Obedecer / Desobedecer** | a + OI | *Obedeceu **às** regras.* |
| **Pagar / Perdoar** (pessoa) | a + OI | *Pagou **ao** funcionário. / Perdoou **ao** inimigo.* |
| **Pagar / Perdoar** (coisa) | OD | *Pagou **a** dívida. / Perdoou **o** erro.* |
| **Chegar / Ir** | a | *Chegou **ao** trabalho.* |
| **Morar / Residir** | em | *Mora **em** Brasília.* |
| **Implicar** (acarretar) | OD | *Isso implica **mudança**.* |
| **Implicar** (antipatizar) | com | *Implica **com** tudo.* |

## Regência Nominal — Nomes de alta incidência

| Nome | Preposição | Exemplo |
|---|---|---|
| Acessível | a | *acessível **ao** público* |
| Ansioso | por | *ansioso **por** resultados* |
| Capaz | de | *capaz **de** resolver* |
| Necessário | a | *necessário **ao** projeto* |
| Compatível | com | *compatível **com** o sistema* |
| Favorável | a | *favorável **à** proposta* |

---

## Erros Clássicos
1. "Visar o crescimento" ❌ (objetivo) → "Visar **ao** crescimento" ✅
2. "Assistir o filme" ❌ → "Assistir **ao** filme" ✅
3. "Prefiro café mais do que chá" ❌ → "Prefiro café **a** chá" ✅
