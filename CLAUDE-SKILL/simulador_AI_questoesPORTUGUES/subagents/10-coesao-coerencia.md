# Coesão e Coerência Textual

## Coesão Textual

### Definição
Propriedade que garante a **ligação formal** entre as partes do texto por meio de recursos linguísticos.

### Tipos de coesão

#### Referencial (retomada de termos)
| Tipo | Mecanismo | Exemplo |
|---|---|---|
| Anáfora | Retoma elemento anterior | *Maria chegou. **Ela** estava cansada.* |
| Catáfora | Antecipa elemento posterior | ***Isso** é certo: ele virá.* |
| Substituição por sinônimo | Troca por palavra de sentido similar | *O presidente... **o mandatário***... |
| Elipse | Omissão de elemento recuperável | *João foi ao mercado; [João] comprou pão.* |

#### Sequencial (progressão temática)
| Recurso | Valor semântico | Exemplo |
|---|---|---|
| **Porém / contudo / todavia / entretanto** | Oposição/contraste | *Estudou; **contudo**, não passou.* |
| **Portanto / logo / assim / por conseguinte** | Conclusão | *Estudou; **portanto**, passou.* |
| **Além disso / ademais / outrossim** | Adição / progressão | *É competente. **Além disso**, é honesto.* |
| **Por exemplo / isto é / ou seja** | Explicação/exemplificação | *Há várias opções, **por exemplo**, a concessão.* |
| **Embora / apesar de / ainda que** | Concessão | ***Embora** cansado, continuou.* |
| **Porque / pois / visto que** | Causalidade | *Não veio **porque** estava doente.* |
| **Se / caso / desde que** | Condição | ***Se** chover, ficamos.* |

## Coerência Textual

### Definição
Propriedade que garante a **unidade de sentido** do texto — relação lógica e semântica entre as ideias.

### Princípios de coerência

| Princípio | Violação típica |
|---|---|
| **Não contradição** | Afirmar X e depois negar X sem ressalva |
| **Não tautologia** | Repetir a mesma ideia com palavras diferentes sem acrescentar nada |
| **Relevância** | Incluir informação sem relação com o tema central |
| **Continuidade temática** | Mudar de assunto abruptamente |
| **Progressão** | Não avançar — repetir sem aprofundar |

### Coesão vs. Coerência

| Critério | Coesão | Coerência |
|---|---|---|
| Nível | Superficial (forma) | Profundo (sentido) |
| Avaliação | Gramatical | Semântico-lógica |
| Exemplo de problema | Pronome sem referente claro | Texto com ideias contraditórias |

> Um texto pode ser coeso e incoerente (bem conectado, mas sem sentido lógico) ou coerente e sem coesão (sentido claro, mas com ligações formais precárias).

---

## Questões de Coesão em Concursos — O que a banca testa

1. **Valor semântico dos conectivos** — substituir "porém" por "portanto" e perguntar se o sentido se mantém.
2. **Referência ambígua** — pronome que pode retomar dois antecedentes diferentes.
3. **Conectivo inadequado** — usar "logo" (conclusão) onde a relação é de contraste.
4. **Ruptura de coerência** — parágrafo que contradiz o argumento central.

## Conectivos mais cobrados em concursos

| Valor | Conectivos |
|---|---|
| Adição | e, também, além disso, ademais, outrossim |
| Oposição/contraste | mas, porém, contudo, todavia, entretanto, no entanto |
| Conclusão | logo, portanto, assim, por conseguinte, então |
| Causa | porque, pois, visto que, já que, uma vez que |
| Concessão | embora, apesar de, ainda que, mesmo que |
| Condição | se, caso, desde que, contanto que |
| Finalidade | para que, a fim de que |
| Tempo | quando, enquanto, assim que, logo que, antes que |
| Explicação | isto é, ou seja, a saber, por exemplo |
