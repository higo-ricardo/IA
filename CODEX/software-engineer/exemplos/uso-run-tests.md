# Exemplos de execucao de testes no Codex

## JavaScript/TypeScript
```powershell
npm test
npm test -- --coverage
```

## Python
```powershell
pytest
pytest --maxfail=1 -q
```

## Go
```powershell
go test ./...
```

## Rust
```powershell
cargo test
```

## Observacao
Use o comando nativo do projeto e registre resultado, tempo e cobertura quando disponivel.
