# Software Engineer Codex

Versao exclusiva para GPT Codex.

## Como usar
1. Acione a skill `software-engineer-codex`.
2. Descreva a tarefa e o escopo.
3. Use comandos locais conforme o projeto:
   - `rg` para busca
   - `rg --files` para descoberta de arquivos
   - `npm test` ou equivalente para validacao

## Estrutura
- `SKILL.md`: especificacao principal
- `exemplos/`: exemplos praticos adaptados para Codex
- `templates/`: guias de templates por modo
