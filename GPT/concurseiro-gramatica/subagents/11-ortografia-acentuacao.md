# Ortografia e Acentuação Gráfica

## Acentuação — Regras Gerais (pós-Acordo Ortográfico 2009)

### Oxítonas (última sílaba tônica)
Acentuam-se as terminadas em: **a(s), e(s), o(s), em, ens**
- *café, avó, também, armazéns, cipó*

### Paroxítonas (penúltima sílaba tônica)
Acentuam-se as terminadas em: **l, r, n, x, ps, ã(s), ão(s), ei(s), i(s), us, um, uns**
- *fácil, açúcar, hífen, tórax, bíceps, ímã, órgão, jóquei (não mais), táxi, vírus, álbum*

> ⚠️ Paroxítonas terminadas em **-a, -e, -o, -am, -em** (comuns) **NÃO** se acentuam:  
> *casa, come, livro, falam, ontem*

### Proparoxítonas (antepenúltima sílaba tônica)
**Todas** se acentuam.
- *médico, lâmpada, ônibus, público, sílaba*

## Mudanças do Acordo de 2009 (mais cobradas)

| Antes | Depois | Observação |
|---|---|---|
| pára (verbo) | para | Acento diferencial eliminado |
| pélo / pêlo | pelo | Eliminado |
| pólo / pôlo | polo | Eliminado |
| vôo, zôo | voo, zoo | Hiato com vogais iguais — eliminado |
| lêem, vêem | leem, veem | Idem |
| fôrma (molde) | forma | Eliminado |
| **mantém** o acento: **pôr** (verbo) vs **por** (preposição) | | Ainda válido |
| **mantém** o acento: **pôde** (pretérito) vs **pode** (presente) | | Ainda válido |

## Dígrafo vs. Hiato vs. Ditongo

| Conceito | Definição | Exemplo |
|---|---|---|
| Dígrafo | Duas letras = um som | *nh, lh, ch, ss, rr, qu, gu* |
| Hiato | Duas vogais em sílabas diferentes | *sa-ú-de, po-e-ta* |
| Ditongo | Vogal + semivogal na mesma sílaba | *pai, meu, ceu* |

## Ortografia — Casos mais cobrados

### S ou Z?
- **-eza** (qualidade de adjetivo): *beleza, riqueza, fraqueza*
- **-isa / -osa**: *poetisa, gostosa*
- **-izar / -isar**: verbos com radical terminado em **s** → **isar** (*analisar, avisar*); demais → **izar** (*civilizar, organizar*)

### X ou CH?
- **x** após ditongo: *caixa, frouxo, feixe*
- **x** após "en-": *enxada, enxoval*
- **ch** em palavras de origem estrangeira ou consagradas: *chave, cheque, chiclete*

### G ou J?
- **-agem / -igem / -ugem**: *viagem, origem, ferrugem*
- **-ger / -gir** (verbos): *eleger, dirigir*
- **-jer / -jir** (exceções): *enjeitar, viajar (derivados de viagem)*

### Parônimos frequentes em prova

| Par | Diferença |
|---|---|
| *descriminar* (tirar do crime) × *discriminar* (distinguir/segregar) | ⚠️ Muito cobrado |
| *deferir* (conceder) × *diferir* (divergir/adiar) | |
| *infligir* (impor pena) × *infringir* (violar) | |
| *emergir* (vir à tona) × *imergir* (mergulhar) | |
| *seção* (divisão) × *sessão* (reunião) × *cessão* (ato de ceder) | |

## Erros Clássicos de Prova
1. Acentuar paroxítona regular: *"cómodo"* ❌ — paroxítona terminada em -o, sem acento (não é proparoxítona; na verdade *cômodo* é paroxítona com ô — atenção: **cômodo** está correto por ter vogal fechada + acento circunflexo histórico, mas "comodo" com acento agudo está errado)
2. Confundir *discriminar* com *descriminar*
3. Usar acento diferencial eliminado pelo Acordo: *"pára"* com acento ❌
4. Não reconhecer hiato tônico: *saída, raiz, país* — acentuados por serem i/u tônicos em hiato
