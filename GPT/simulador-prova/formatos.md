# Formatos de Questão

> Carregar ao gerar/exibir qualquer questão durante a prova.

---

## Formato 1 — V/F (Certo / Errado)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

Afirmativa:
"[TEXTO DA AFIRMATIVA]"

( ) CERTO
( ) ERRADO
```

---

## Formato 2 — Multi (A–E)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

[ENUNCIADO DA QUESTÃO]

A) [alternativa]
B) [alternativa]
C) [alternativa]
D) [alternativa]
E) [alternativa]
```

---

## Formato 3 — Proposições (Tipo A)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

Analise as proposições abaixo:

I.   [proposição]
II.  [proposição]
III. [proposição]

Assinale a alternativa correta:

A) Apenas I é correta
B) Apenas II é correta
C) I e III são corretas
D) II e III são corretas
E) Todas são corretas
```

---

## Formato 4 — Discursiva (DISC)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

[ENUNCIADO DA QUESTÃO DISCURSIVA]

▸ Sua resposta (digite livremente):
```

**Diretrizes:**
- Comando claro (Explique, Compare, Fundamente, Discorra)
- Escopo temático preciso — não excessivamente aberto
- Informar extensão esperada se aplicável (ex: "em até 15 linhas")
- Espelho deve conter: conceito-chave, fundamento legal/doutrinário, raciocínio lógico

---

## Formato 5 — Estudo de Caso (EC)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

📂 ESTUDO DE CASO

[CONTEXTO/NARRATIVA DA SITUAÇÃO-PROBLEMA]
[Detalhes sobre as partes, fatos, prazos, atos praticados etc.]

Com base no contexto apresentado, responda:

[PERGUNTAS SOBRE O CASO — ex: "Qual a medida cabível?", "Houve violação de qual princípio?"]

▸ Sua resposta (discursiva — aborde todos os pontos solicitados):
```

**Diretrizes:**
- Narrativa realista (situações reais ou hipotéticas verossímeis)
- Dados suficientes para análise (prazos, normas, atos)
- Perguntas exigem raciocínio aplicado, não memorização
- Espelho: problema jurídico + normas/princípios + conclusão fundamentada

---

## Formato 6 — Exceto / Incorreto (Exceto)

```
Questão [N]/[TOTAL] · [Nível] · ⏱️ ref. [T]s · [Confidence: X/10]

Sobre [TEMA], assinale a alternativa INCORRETA:

A) [alternativa correta]
B) [alternativa correta]
C) [alternativa INCORRETA — gabarito]
D) [alternativa correta]
E) [alternativa correta]
```

> **Nota**: todas as alternativas são verdadeiras exceto uma. O gabarito é a exceção.

---

> 📝 **Nota geral:** Discursivas e Estudo de Caso não têm "alternativa correta" — correção por espelho (ver `correcao.md`).
