# 08 — Metadados e Publicação

**Agente**: EDITOR  
**Estágio**: M9

---

## Objetivo
Preparar todos os elementos editoriais e de marketing necessários
para publicação em plataformas digitais.

---

## Pacote de Publicação Completo

O EDITOR gera os seguintes elementos:

### 1. Blurb (Sinopse de Venda)

**Fórmula padrão**:
```
[Pergunta ou afirmação que ressoa com a dor do leitor] (1-2 frases)

[Promessa do livro — o que o leitor vai conquistar] (1-2 frases)

[Prova social ou credencial do autor — se houver] (1 frase)

[Chamada para ação] (1 frase)
```

Gerar **2 versões**: curta (100 palavras) e longa (250 palavras).

### 2. Metadados para Plataformas

```yaml
titulo: "..."
subtitulo: "..."
autor: "..."
genero_principal: "..."
subgenero: "..."
palavras_chave:
  - "..."
  - "..."
  (8-10 palavras-chave)
idioma: "Português (Brasil)"
paginas_estimadas: X
publico_alvo: "..."
classificacao_indicativa: "..."
isbn: "pendente"
```

### 3. Categorias por Plataforma

**Amazon KDP**:
- Categoria 1: [caminho completo]
- Categoria 2: [caminho completo]
- 7 keywords: [lista]

**Hotmart / Eduzz / Monetizze**:
- Categoria: ...
- Subcategoria: ...
- Tags: [lista de 10]

### 4. Página de Vendas (Copy)

Estrutura básica para landing page:

```markdown
# [HEADLINE PRINCIPAL — benefício ou transformação]

## [SUBHEADLINE — complementa ou especifica]

---

### Para quem é este ebook?
[3-5 bullets descrevendo o leitor ideal]

### O que você vai aprender
[6-8 bullets com os principais aprendizados]

### O que está incluído
[Lista dos capítulos com mini-descrição sedutor]

### [CTA] Adquira agora por R$ [X]
[Botão / link]

### Garantia
[X dias de garantia — padrão plataformas BR: 7 dias]
```

### 5. Bio do Autor (se solicitado)

Gerar 3 versões:
- **Curta** (50 palavras): para metadados da plataforma
- **Média** (150 palavras): para página de vendas
- **Longa** (300 palavras): para página "Sobre o Autor" dentro do ebook

### 6. Prompt de Capa para IA

Gerar prompt otimizado para Midjourney / DALL-E / Stable Diffusion:

```
[estilo visual], [paleta de cores], [elementos centrais],
[tipografia sugerida], [mood/atmosfera], [referências visuais],
aspect ratio: 6:9 (Kindle/ebook padrão)
```

---

## Checklist Pré-Publicação

- [ ] Blurb (curto e longo) revisado
- [ ] Metadados completos
- [ ] Palavras-chave pesquisadas (volume de busca)
- [ ] Página de vendas redigida
- [ ] Capa criada ou prompt gerado
- [ ] Formato de arquivo correto para a plataforma
- [ ] ISBN obtido (se necessário)
- [ ] Direitos autorais e copyright na página de rosto
- [ ] Informações de contato / redes sociais do autor
- [ ] Chamada para ação final dentro do ebook (próximo produto, lista de e-mail)
