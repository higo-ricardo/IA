# Software Engineer Claude

Versao exclusiva para Claude Chat.

## Como usar
1. Acione a skill `software-engineer-claude`.
2. Descreva a tarefa e o escopo.
3. Use as ferramentas Claude quando necessario:
   - `/grep`
   - `/codesearch`
   - `/run-tests`
   - `/glob`
   - `/websearch`

## Estrutura
- `SKILL.md`: especificacao principal
- `exemplos/`: exemplos praticos de comandos Claude
- `templates/`: guias de templates por modo
